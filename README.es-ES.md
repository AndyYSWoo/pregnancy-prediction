

# Predicción del Embarazo
Este repositorio proporciona el código fuente del artículo: [Predicción del embarazo utilizando datos a gran escala de una aplicación móvil de seguimiento de salud femenina](https://arxiv.org/abs/1812.02222).

## Descripción de Archivos
`main.py`: punto de entrada principal de los modelos

`data_gen.py`: un generador de datos sintéticos

`demo_on_how_to_run_models.ipynb`: notebook para ilustrar cómo generar datos y ejecutar modelos

`models/`: implementación de los diferentes modelos mencionados en el artículo
